# OPC Lab

面向 AI 编程与一人公司（One Person Company）创造者的社区首页。网站使用原生 HTML、CSS 和 JavaScript 构建，无需安装依赖即可运行。

## 本地预览

```bash
python3 -m http.server 4173
```

打开 <http://localhost:4173>。

## 部署

推送到 GitHub 的 `main` 分支后，GitHub Actions 会自动将网站部署至 GitHub Pages。首次使用时，请在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。
